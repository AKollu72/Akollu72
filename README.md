### 🔧 Fixel — [repo](https://github.com/AKollu72/fixel) · [npm](https://www.npmjs.com/package/fixel)

If you generate React from Figma with AI, Fixel locks the exact design
values and fails CI when they drift. Deterministic token resolution
before generation, prohibited-pattern enforcement, spec-locked CI
verification, Figma canvas annotation — plus an MCP server so coding
agents can verify their own output (tested end-to-end with Claude Code).

```sh
npx fixel scan ./src   # no config, no API key, 10 seconds
```
